# 医学资料准备清单（Knowledge Catalog）

> 智能体出厂自带 12 篇**基础医学知识**（危急值/药物相互作用/正常范围/常见急症处理等）。
> 要让它在真实临床中有更强的专业能力，请按本清单把**外部医学资料**（PDF / DOCX 等）导入知识库。
> 我们无法内置整本医书（体积所限），但**你只需要准备好"这些类型的资料"并导入**，智能体即可检索到并引用。

## 优先级说明
- **P0 必配**：全院通用、几乎所有问答都会用到，强烈建议优先导入。
- **P1 高优先**：按科室场景选择，覆盖日常临床高频问题。
- **P2 可选**：纵深专科或特定业务需要时再导入。

## 使用建议
1. **按科室分目录**：在知识库中为每个科室建子目录（如 `临床知识/外科/手术学.pdf`），便于管理与检索。
2. **优先文本版 PDF**（可选中复制）；扫描件需 OCR（DoctorAgent 支持文本抽取）。
3. **定期更新**：指南/共识有版本，及时替换旧版。
4. **命名规范**：建议 `科室_资料名_版本.pdf`，便于智能体定位与引用。
