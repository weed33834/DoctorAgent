# DoctorAgent 合规路线图

> ⚠️ 本文档描述的合规认证为**路线图目标**，当前产品尚未取得任何认证。
> 在取得相应资质前，本产品不作为医疗器械销售或使用。

## 1. 医疗器械认证（NMPA）

### 现状
- 本产品定位为临床决策支持工具（CDS），不替代医生诊断
- `pyproject.toml` 明确声明 "certification is a roadmap goal, not yet certified"

### 计划
1. **分类界定**（T+0~3个月）
   - 委托医疗器械注册咨询机构进行分类界定
   - 预期分类：二类医疗器械（CDS Hooks + 用药安全提醒）
   - 如涉及诊断建议功能，需重新评估是否升级为三类

2. **注册申报**（T+3~12个月）
   - 准备技术文档（产品技术要求、说明书）
   - 临床评价（同品种比对或小规模临床验证）
   - 质量管理体系（GMP）建立

3. **获证**（T+12~18个月）
   - 取得 NMPA 二类医疗器械注册证

## 2. 生成式 AI 算法备案

### 法律依据
- 《互联网信息服务深度合成管理规定》（2023年1月10日施行）
- 《生成式人工智能服务管理暂行办法》（2023年8月15日施行）

### 计划
1. **算法安全评估**（T+0~2个月）
   - 完成算法机制说明
   - 安全评估报告（偏见、安全、隐私）

2. **备案申报**（T+2~4个月）
   - 向网信办提交算法备案
   - 提供模型训练数据说明（本产品使用通用大模型，无自主训练）

## 4. 数据安全合规

### 中国三法合规
- [ ] 《个人信息保护法》合规评估
- [ ] 《数据安全法》数据分类分级
- [ ] 《网络安全法》安全保护义务
- [ ] 《医疗健康数据安全指南》（YD/T 3947-2021）对标

### 数据出境
- 默认配置应使用本地化知识源（见数据源本地化配置）
- 如需调用海外 API（openFDA/PubMed），需进行数据出境安全评估

### HIPAA 合规（国际市场）
- [x] PHI 脱敏（HIPAA Safe Harbor 18 类标识符）
- [x] HMAC 审计链（21 CFR Part 11）
- [x] AES-256-GCM 加密
- [ ] BAA（Business Associate Agreement）模板
- [ ] 第三方安全审计

## 5. IRB 伦理审查

### 计划
- 在开展任何涉及患者数据的临床验证前，必须先获得 IRB 批件
- 准备知情同意书模板
- 回顾性研究可申请豁免知情同意

## 6. 当前合规自检状态

DoctorAgent 内置合规自检工具（`clinical/compliance_report.py`），覆盖：
- 加密（AES-256-GCM + 三层密钥体系）
- 审计日志（HMAC 签名 + 不可篡改）
- 访问控制（RBAC + 7 角色 + 临床角色）
- PHI 保护（18 类标识符脱敏）
- 密钥管理（轮换 + Shamir 门限）
- 数据驻留（本地优先 + 云默认关闭）

> 注意：自检工具生成的是自我评估报告，**不等于**第三方认证。
