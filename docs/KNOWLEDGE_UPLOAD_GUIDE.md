# 知识库导入操作引导（Knowledge Upload Guide）

> 本文面向**医院运维 / 科室资料管理员**，说明如何把《医学资料准备清单》
> （KNOWLEDGE_CATALOG.md）中的 PDF / DOCX 等资料导入 DoctorAgent 知识库，
> 让智能体开箱即可检索引用。**全程不写代码**，三种方式任选。

---

## 一、概览

导入的文档会进入 **Vault（文档库）**，经处理后建立索引，智能体在对话中即可
检索并引用。核心路径：

```
上传/导入 → Inbox(收件箱) → 分类 → Vault(知识库) → 索引 → 对话可检索
```

## 二、方式一：控制台上传（推荐，无需命令行）

1. 打开 DoctorAgent 控制台，进入「📁 文档 Vault」视图。
2. 使用聊天栏的**上传按钮**（或直接把文件拖进聊天区），选择要导入的 PDF。
3. 系统自动把文件放入 Inbox 并处理，随后出现在 Vault。
4. 处理完成后，在对话里提问，即可检索到该书内容。

> 若你希望走**更明确的知识库导入**，调用（需要令牌，管理员提供）：
> ```bash
> curl -X POST http://<host>/api/v1/vault/import \
>   -H "Authorization: Bearer <TOKEN>" \
>   -F "file=@/path/to/医学书.pdf"
> ```
> 返回的 `task_state=COMPLETED` 即入库成功。

## 三、方式二：命令行导入（适合批量）

```bash
# 单文件
doctoragent import /data/医学书/内科学.pdf

# 整个目录（含子目录）
doctoragent import --dir /data/医学书/外科/

# 导入后立即看到结果
doctoragent import /data/指南/2024_高血压指南.pdf
```

导入完成后，`doctoragent ask "某本书里关于……"` 即可验证可检索。

## 四、方式三：直接放入 Inbox 目录（服务运行时自动处理）

1. 找到 Inbox 目录（默认 `~/DoctorAgent/Inbox`，可用 `doctoragent status` 查看实际路径）。
2. 把 PDF 直接拷进 Inbox。
3. 运行中的 DoctorAgent 会**自动**检测新文件、分类并移入 Vault。
4. 等待几秒到几十秒（文件越大越久），到 Vault 视图确认已入库。

## 五、验证是否检索得到

导入后，用下面任一方式确认智能体能引用到：

1. **对话验证**：问一个书中才有的细节问题，例如"《内科学》里对心衰的分型是什么？"，
   看回答是否引用该书。
2. **检索接口**：
   ```bash
   doctoragent search "高血压 一线用药"
   ```
   或在控制台「文档 Vault / 高级 RAG」中搜索关键词，看是否命中该书。
3. 若未命中：确认文件已进入 Vault、文件名无特殊字符、内容非纯扫描件（需 OCR）。

## 六、最佳实践

| 建议 | 说明 |
|---|---|
| 按科室分目录 | 在 Vault 建 `临床知识/外科/` 等子目录，利于管理 |
| 优先文本版 PDF | 可选中复制的文本版，检索准确度最高 |
| 扫描件先 OCR | 扫描版 PDF 需 OCR 后导入；DoctorAgent 的文档抽取支持常见格式 |
| 文件名规范 | `科室_资料名_版本.pdf`（如 `心内_高血压指南_2024.pdf`） |
| 拆分大文件 | 整本大部头可拆成章节，检索更精准 |
| 定期更新 | 指南/共识有版本，及时替换旧版 |
| 隐私与权限 | 含 PHI 的资料遵循机构规范；控制台已内置脱敏与审计 |
| 格式 | 支持 PDF / DOCX / XLSX / MD / TXT / CSV 等；图片/音频有抽取器 |

## 七、常见问题

- **导入后搜索不到？**
  确认进入 Vault、命名简单、非扫描件；或稍等索引完成，重启 `doctoragent` 后再试。
- **一次最多传多大？**
  控制台上传单文件 ≤ 50MB；大文件建议拆分或走目录导入。
- **PDF 里的图/表能检索吗？**
  文本可检索；图表类请尽量提供文字版说明或 OCR。
- **会不会误读患者隐私资料？**
  文档库默认用于临床文献/指南；含患者资料的文档请按机构 PHI 规范处理，系统自带脱敏与审计。
