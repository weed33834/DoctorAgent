# DoctorAgent（医師エージェント）

> 臨床 AI 医師エージェント · Clinical AI agent for doctors
>
> セルフホスト型の臨床意思決定支援（CDS）エージェント：決定論的な薬物相互作用 / 異常値安全ルール + マルチエージェント LLM 推論。FHIR R4、CDS Hooks 2.0、SMART-on-FHIR、PHI マスキング、RAG 文献ライブラリ、HMAC 監査チェーンを備える。

## これは何

DoctorAgent は「決定論的安全ルール」と「マルチエージェント LLM 推理」を組み合わせ、臨床医の薬物レビュー・文献検索・PHI 処理・診療記録作成を支援します。ローカル完結で動作し、Ollama などのローカル LLM にもクラウド LLM にも接続できます。

1. **安全ルールは完全オフライン**。5 種類の決定論的チェック（異常値 / 検査値 / DDI / アレルギー / 重複投与）は LLM を呼ばずに実行。ルールと LLM の意見が衝突したら常にルールが優先。
2. **データはあなたのハードウェアに**。Vault（文献庫）は AES-256-GCM 暗号化、監査ログは HMAC-SHA256 チェーン署名。完全オフライン運用が可能。
3. **標準統合は実装済み**。CDS Hooks 2.0 エンドポイント、FHIR R4 ハンドラ、SMART-on-FHIR 認証、SNOMED CT / LOINC / ICD-10-CM 用語バインディング。

現在のバージョンは Beta です。FDA 510(k)、HIPAA 認証、等保三級は未取得（Roadmap）。誠実な現状表は [コンプライアンス](#コンプライアンス) を参照。

## アーキテクチャ（一段要約）

FastAPI サーバーが API と Web コンソール（Vue 3 + Vite）を両方提供します。入力文書は：分類器 → AES-256-GCM 暗号化保存 → SQLite FTS5 + ベクトルインデックス → 検索パイプライン → エージェント（病歴 → 投薬 → 文献 → 文書の固定 DAG）。各ステップは HMAC 監査チェーンに記録されます。

固定 DAG の設計は譲れない要件です——臨床ワークフローがコンパイルされた後、LLM は安全ステップを迂回できません。

## クイックスタート

Python 3.10+、約 200MB のディスク。

```bash
git clone https://github.com/weed33834/DoctorAgent.git
cd DoctorAgent
pip install -e ".[server]"
cd frontend && npm install && npm run build && cd ..
bash start.sh
```

ブラウザで <http://127.0.0.1:8000/console/> を開く。安全ルールエンジンと文献庫は LLM キーなしで動作します。Ollama やクラウド LLM を接続するとエージェント機能が解放されます。

### 動作確認

```bash
pytest tests/ -q
```

## 臨床機能

- **薬剤安全レビュー**：DDI / アレルギー交差反応 / 重複投与検出
- **異常値警報**：バイタルサインと検査値の閾値評価
- **診療文書**：SOAP 形式生成、ICD-10 コーディング支援
- **文献検索**：PubMed / Vault RAG、すべての回答に引用元を添付
- **専門医ロール**：18 専門の組込みペルソナ（循環器 / 外科 / 麻酔 / 救急 / ICU / 小児…）
- **組込み医学ナレッジベース**：基礎医学ドキュメント 12 本を起動時に自動シード

## プラットフォーム機能

- 対話による操作（科室切替・知識ベース管理・システム状態照会など）
- サーバーサイド会話（永続化 / 検索 / フォーク / 共有 / 自動タイトル / 要約）
- ReAct ループ、MCP クライアント+サーバー、A2A プロトコル（デフォルト無効）、コードサンドボックス
- RBAC + OIDC + MFA(TOTP)、マルチテナント、監査チェーン、Prometheus/OTel/Langfuse 観測性

外部コンポーネントとの接続方法（Ollama / vLLM / Speaches / HAPI FHIR / Langfuse など）は [`docs/INTEGRATIONS.md`](docs/INTEGRATIONS.md) を参照。

## 商用利用

コードは Apache-2.0。医院内利用・マネージドサービス・製品組み込みいずれも可。ただし派生物から**監査チェーンと決定論的安全ルールを削除すること**はサポートしません。

## ライセンス

Apache-2.0。同梱の SNOMED CT / LOINC / ICD-10-CM 参照データは各ライセンスに従う（`docs/COMPLIANCE_ROADMAP.md` 参照）。
