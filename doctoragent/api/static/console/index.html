PHI 脱敏

对临床文本中的受试者健康信息（PHI）做识别与脱敏，支持手机号、邮箱、身份证、姓名、地址等实体。三种策略：redact 擦除、pseudonymize 假名替换、mask 掩码。

脱敏结果

🛡️

尚未执行脱敏

输入临床文本并选择策略，点击「脱敏」即可查看 PHI 识别、原文 / 脱敏对比与实体类型分布。

确定性安全规则清单

LLM 无关的确定性规则引擎：生命体征危急值、检验异常、药物相互作用、过敏交叉反应等。规则先行，构成不可绕过的安全底线。

点击「加载规则」查看已注册的确定性安全规则。

规则试跑（patient_context）

编辑患者上下文 JSON，对确定性规则引擎试跑，查看命中的 findings（按 severity 着色：critical / warning / info）。

编辑上下文后点击「试跑规则」。

多智能体编排拓扑

基于 LangGraph 声明式 DAG：确定性规则 → 三路并行专家（病史 / 药物 / 文献）→ 聚合 → 文书 → 护栏。图一旦编译即不可变，LLM 无法在运行时改写流程，保证可审计的固定 DAG。鼠标悬停节点查看说明。

确定性 专家 Agent 聚合

点击「获取拓扑」渲染编排图。

知识图谱管理

从 Vault 文档中抽取实体与关系，构建医疗知识图谱。支持图谱构建、语义查询、实体详情、子图可视化。

图谱查询

子图可视化

DAG 工作流引擎

通用 DAG 任务编排引擎：定义任务节点与依赖关系，拓扑排序后并行执行，支持重试、超时、条件分支、取消。

DAG 任务定义

用 JSON 定义任务列表，每个任务含 id / name / dependencies / params / max_retries / timeout_seconds。

执行状态

RAG / Agent 评估

对 RAG 和 Agent 输出做多维度评估：Faithfulness（忠实度）、Answer Relevancy（答案相关性）、Context Precision/Recall（上下文精确率/召回率）。支持 LLM Judge（需配置 judge_model + api_key）或确定性降级。

评估报告

填写输入与输出后点击「运行评估」。

自进化引擎

分析 Agent 执行轨迹，提取经验教训，优化 Prompt 与工具选择。经验持久化到 SQLite，可召回复用。

轨迹查看

查看指定 task_id 的 Agent 执行轨迹（每步 step_type / content / tool_name）。

Tree-of-Thought 推理

对复杂问题做多分支探索，返回最佳推理路径与完整搜索树。GET 请求，query 必填。

RAG 路由

智能查询路由：根据问题类型自动选择检索策略（factual / hybrid / semantic）。

Agentic RAG

多轮迭代检索：Agent 自主决定是否需要更多检索，最多 N 轮。返回最终答案 + 文档 + 行动历史。

Corrective RAG

自纠正检索：评估检索质量，若不足则改写查询重新检索，最多 N 轮。返回文档 + 评估 + 修正 trace。
